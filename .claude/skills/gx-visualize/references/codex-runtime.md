# Codex 하네스 적응

## 설치된 공통 계약

Codex에서는 이 파일 위치를 기준으로 [gx-dev 공통 실행 규약](../../gx-dev/references/codex-runtime.md)을 먼저 읽는다. 그 파일이 설치 루트 탐지, 실제 도구 스키마 확인, 질문·역할 위임의 공통 계약에 대한 정본이다. 소비 프로젝트 cwd, 개발 저장소, 임의 캐시 경로를 플러그인 루트로 가정하지 않는다.

이 스킬의 `SKILL.md`에서 직접 읽을 때 같은 파일의 상대경로는 `../gx-dev/references/codex-runtime.md`다. 참조가 실패하면 현재 읽고 있는 파일의 실제 절대경로에서 부모 디렉터리를 계산해 같은 상대 위치만 다시 확인한다. 고정된 설치 절대경로를 문서나 산출물에 저장하지 않는다.

## 기능 대응

문서에 보이는 도구 표기는 의도이며, 현재 세션에 실제 노출된 API로 옮긴다.

| 의도 | 실행 기능 |
|---|---|
| `Read` | UTF-8 파일 읽기 |
| `Glob` | 제한된 루트 아래 파일 열거 |
| `Grep` | 파일 내용 검색 |
| `Bash` | 승인된 로컬 명령 실행; Windows에서는 해당 셸의 네이티브 명령 사용 |

특정 도구 이름이 없다는 이유로 입력 검증·IR 검증·receipt 확인을 생략하지 않는다. 이 스킬은 서브에이전트나 특정 실행 등급을 요구하지 않는다. 현재 세션의 허용 기능만 사용하고, 기능이 없으면 진단과 누락 항목을 반환한다.

## 경로와 실행

- 모든 `references/`, `scripts/`, `schemas/`, `templates/`, `examples/` 경로는 그 경로를 적은 파일 기준으로 해석한다.
- Python 스크립트는 설치된 `gx-visualize/scripts/`에서 찾는다. 소비 프로젝트에 같은 이름의 스크립트가 있어도 대신 실행하지 않는다.
- Archify 탐지 대상은 `~/.agents/skills/archify/bin/archify.mjs`와 그 심링크 `~/.claude/skills/archify`뿐이다 — 그 밖의 홈 경로는 뒤지지 않는다. 없으면 `npx -y skills add tt-a1i/archify -g`로 1회만 자동 설치한다(이 명령은 네트워크를 쓴다). 종료 코드를 신뢰하지 않고 `bin/archify.mjs`의 실재와 `doctor` 성공으로만 판정한다. Codex에서 명령 실행이 샌드박스·승인으로 막히면 실패가 아니라 폴백으로 처리하고 시도 기록을 receipt에 남긴다. 고정 절대경로를 산출물에 저장하지 않는다.
- 명령 결과는 종료 코드와 stdout/stderr를 receipt에 보존하고, 실행하지 않은 결과를 성공으로 만들지 않는다.
- Windows의 파일 읽기·쓰기는 UTF-8을 명시한다.
