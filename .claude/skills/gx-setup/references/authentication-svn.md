> gx-setup/SKILL.md의 VCS_TYPE이 svn일 때만 읽는다. 변수·소비 프로젝트 경로는 원래 스킬을 따른다.

### 2단계: 인증

**svn인 경우** → 로컬 작업 복사본 정보만 확인한다. 로컬 정보의 성공은 원격 인증·자격 증명 캐시의 증거가 아니다:

1. URL 없이 `svn info`로 현재 작업 복사본의 로컬 메타데이터를 확인한다.
   - 성공 → `SVN 작업 복사본 : 확인`과 `SVN 인증 : 미확인 (로컬 정보만 확인)` 출력. 원격 접속·캐시 인증 성공으로 표시하지 않는다.
   - 실패 → `SVN 작업 복사본 : 미확인`으로 표시하고 실제 CLI/경로 오류를 보고한다. 인증 오류로 단정하지 않는다.
   - 원격 인증이 필요한 사용자는 직접 아래 절차를 수행하도록 안내한다. setup이 원격 명령을 실행하거나 자격 증명을 수집하지 않는다:
     ```
     SVN 원격 인증은 확인하지 않았습니다.

     보안상 SVN 사용자명/비밀번호를 대화로 수집하지 않습니다.
     터미널에서 직접 아래 명령으로 자격 증명을 캐시한 뒤 다시 실행해주세요:

       svn info <저장소 URL>

       인증 캐시 여부는 SVN 클라이언트와 사용자 설정에 따라 달라집니다.
     ```
   - 인증 미확인 상태를 유지하고 다음 독립 설정 단계로 진행.

2. **주의**: 어떤 경우에도 AskUserQuestion으로 사용자명/비밀번호를 수집하지 않는다. 비밀번호는 프롬프트 히스토리, 세션 로그, 옵션 description 등에 노출될 위험이 있다.
