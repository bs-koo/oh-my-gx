# 전체·핵심 모드 요구사항 문답 개선

> **For agentic workers:** 기존 보조 스킬 변경을 보존한다. 테스트 작성자는 신규 회귀 파일만 소유하고, 부모가 공통 계약·phase·역할·안내를 수정한다. 독립 리뷰는 읽기 전용으로 수행한다.

**Goal:** 중요한 미정이 해소될 때까지 두 모드가 질문·실제 답변·후속 질문을 반복한다. 핵심 모드는 추가 에이전트 없이 오케스트레이터가 수행한다.

**Architecture:** 새 helper·상태 필드 없이 `requirements-dialogue.md`를 판단 정본으로 두고 기존 질문 대기·결정 기록과 승인 절차를 재사용한다. requirements 앞과 design/implement 재사용·단독 진입, phase 완료에서 같은 조건을 확인한다. 문답 해소와 산출물 승인을 구분한다.

**Tech Stack:** Markdown phase·역할 계약, 기존 Python 질문 helper, unittest 임시 파일 회귀와 읽기 전용 문서 모의평가.

**Spec:** [문답 검토·보강안](../../reports/2026-11-10-core-interview-review.md)과 아래 사용자 승인 범위.

**승인:** 사용자의 “전체모드랑 핵심모드 둘 다 중요한 미정이 해소될 때까지 문답하도록 보완…수정 후 엣지케이스 검증이랑 리뷰” 요청이 실행 범위다. 커밋·PR·설치 cache 갱신은 포함하지 않는다.
