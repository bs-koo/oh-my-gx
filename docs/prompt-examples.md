# 요청 예시

```text
/gx-work 이 요구사항 문서로 기능 만들고 PR까지 올려줘
/gx-work 알림 정책 아이디어를 정리하고 계획까지만 만들어줘
/gx-work W01 시작해줘
/gx-work 다음에 할 수 있는 작업을 알려줘
/gx-work 이 계획대로 테스트 먼저 구현해줘
/gx-work 아까 하던 작업 이어서 해줘
/gx-tdd --full-tests 결제 취소 회귀까지 확인해줘
/gx-work 결제 취소 구현 끝났어. 재시도에서 빠진 엣지케이스를 조사해줘
/gx-edge-cases --base main src/orders/
```

구현·커밋·PR은 요청한 종료점을 따릅니다. 적지 않으면 gx-work가 진입 때 묻고 PR까지를 추천하며(SVN은 검증까지), 직접 gx-tdd 호출은 검증까지입니다. 엣지케이스 조사는 변경 코드와 테스트를 읽고 발견 사항을 보고하는 단계에서 끝납니다. [사용 가이드](guide.md)에 설정과 인계 형식이 있습니다.
