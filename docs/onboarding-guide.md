# 시작하기

설치 후 `/gx-work <요청>`으로 시작합니다. 목적과 어디까지 진행할지만 알려주세요. 계획만 요청하면 제품 코드를 작성하지 않고, 개발 실행은 TDD로 수행합니다.

[사용 가이드](guide.md)에서 계획·재개·테스트 범위·설정을 확인하세요.

## 이전 버전에서 넘어올 때

- **gx-dev**(v2.0.0에서 제거): 새 요청은 `/gx-work`로 시작합니다. 기존 gx-dev 진행 상태는 보존만 하고 자동으로 재개하거나 TDD 상태로 바꾸지 않습니다.
- **Ralph 무인 반복**(`gx-ralph`·`--ralph`, v3.0.0에서 제거): `--ralph`나 "랄프로 개발해줘" 요청은 지원 중단을 알리고 실행하지 않습니다. 일반 개발이나 커밋으로 자동 대체하지도 않습니다. 남은 진행 상태·`ralph.lock`·작업 기록은 지우거나 바꾸지 않으며, 진행 중 기록이나 잠금이 남은 브랜치에서는 커밋·PR이 중단됩니다.

제거된 실행의 진행 상태가 남은 브랜치는 그대로 이어가지 않습니다. 실행 중인 외부 러너가 있으면 먼저 종료하고, 미커밋 변경이 없으면 베이스 브랜치로 돌아가고, 미커밋 변경이 있으면 그 변경이 따라오지 않도록 새 워크트리(`git worktree add <경로> -b <새 브랜치> <베이스>`)를 만든 뒤 `/gx-work <새 목표>`로 시작하세요. 새 작업은 새 브랜치에서 새 실행으로 진행되며, 이전 PRD·AC·커밋은 참고 문서로만 연결됩니다. 완료된 과거 기록은 조회용으로 남습니다.
