# 전체·핵심 요구사항 문답 개선 검증

상태: **수정·최종 로컬 검증·독립 재리뷰 완료**. 작업 경로는 `D:/SQ/oh-my-gx/.claude/worktrees/gx-aux-skill-edges`, 브랜치는 `codex/fix-aux-skill-edges`다. 앞선 보조 스킬 개선을 보존하고 사용자가 추가 승인한 요구사항 문답을 보완했다.

## 변경 범위

- 공통 `requirements-dialogue.md`에서 중요한 미정과 비차단 가정, 답변 근거, 반복·대기·종료 조건을 정의한다.
- 전체는 기존 PO 호출을 재사용하고 핵심은 오케스트레이터가 수행한다. 새 helper·상태 필드·인터뷰 전용 에이전트를 추가하지 않는다.
- requirements의 고정 1회 후속 호출 뒤 미해결 질문 진행을 제거한다. design·implement 단독/재개·기존 승인 재사용·phase 완료에서도 같은 중요 미정을 확인한다.
- 실제 답변 기록과 의미상 해소, 문답 해소와 산출물 승인을 구분한다. 기존 AC/계획 변경의 이력 보관·승인 무효화·재승인을 유지한다.
- read-only·문서 저장 금지 경로는 기존 pending/decisions를 포함해 파일을 쓰지 않고 대화로만 질문한다.

## 기준선과 자동 회귀

수정 전 문서 모의평가에서 전체의 잔여 미정 진행 지시와 기존 질문 대기 규칙의 충돌을 확인했다. core의 명확한 승인 재개·변경된 범위 충돌 차단은 기존대로 보존할 항목이다.

최초 12개 회귀를 수정 전 실행하여 공통 정본·진입/완료 연결 부재 등 계약 실패 7건(subTest 포함)을 확인했다. 기존 helper의 실제 임시 파일 회귀 6건은 이미 통과했다. 이후 단독 phase 원 커서 보존과 종료 문구의 실제 질문 생략 경계를 추가하여 최종 14개가 됐다. 마지막 수정본 기준 전체 14건이 통과했다(정적 계약 7·실제 임시 파일 회귀 7).

후속 RED→GREEN에서는 완료 지점의 ready/waiting 조건, 종료 문구와 실제 질문 목록 충돌, 읽기 전용 조기 완료와 사용자 중단 우선순위, 설계 Step 4의 문자열 기반 질문 생략을 각각 확인했다. 단독 phase 커서 보존은 기존 helper 기능의 보존 검사이며 새 실패를 수정한 것으로 세지 않는다.

자동 검사는 문답 연결 계약과 실제 질문 helper 파일의 후속 라운드·새 token·부분/늦은 응답·ack·별도 승인 pending·조회 무쓰기를 확인한다. 의미적 중요도 판단은 helper가 기계적으로 입증하지 않으므로 문서 모의평가와 독립 리뷰로 구분한다.

모의평가에서 드러난 인접 모순도 보완했다. G-W-T 재작성자는 core 오케스트레이터/전체 PO로 구분했고, 설계 승인과 표시 설명은 요청 범위를 지키도록 맞췄다. testability 미달의 위험 수용 선택지를 제거하여 기존 점수 게이트와 일치시켰다. G-W-T 재작성·설계 검토 상한은 문답 해소를 대신하지 않는다.

실제 설치 cache·질문 UI·인증된 소비 프로젝트의 사용자 응답은 미실행이다. [smoke I1~I5](../../tests/codex-smoke.md)는 별도 실제 세션 시나리오로 유지하며 단위 테스트/모의평가 통과를 그 결과로 승계하지 않는다. 이 기록은 커밋·PR 이전의 로컬 검증 결과이며, 이후 사용자의 PR 게시 요청에 따른 전체 개선 보고는 [통합 보고서](2026-11-10-improvement-summary.md)를 따른다. 설치 cache는 갱신하지 않았다.

로컬 검증 종료 시 기존 사용자 작업 폴더의 파일 지문 48개·HEAD·브랜치가 모두 기존 보존 기록과 일치했고 작업 HEAD는 `6ef7517`였다. 앞선 보조 스킬 변경과 이번 문답 개선은 별도 계획·검증 기록으로 구분한다.
