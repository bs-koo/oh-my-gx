# 개발 문서 정합성과 정책 분석 개선

사용자 승인: 관련 context·요구사항·작업계획을 구현 전에 확인하고 실제 결과를 최종 검증 전에 반영하는 제안 및 gx-lens 개선 요청(2026-11-04). 기존 PR #97의 후속 범위이며 종료점은 PR 반영이다.

1. gx-work·직접 gx-tdd·재개·Ralph 복귀에서 동일한 관련 문서 대조 계약을 적용한다. 읽기 전용·문서 금지 제한과 현재 요청·AC를 보존한다.
2. stdlib 읽기 전용 helper로 전체 원장 구조와 관련 파일 지문을 확인한다. 내용은 관련 FR/W와 변경분만 모델에 전달하고, 부족한 최소 원장/계획만 보강한다.
3. 구현 후 AC 증거와 문서를 먼저 대조하고 최종 verify를 수행한다. 미검증 완료 표식·오래된 FR 완료·최종 검증 후 문서 쓰기를 방지한다.
4. gx-lens에 위치가 있는 근거, 사실/추정/미확인 구분, 선택적 영향 분석, 읽기 전용 근거 검증을 적용한다.
5. 관련 회귀를 RED→GREEN으로 확인하고 전체 Codex 계약·정합성은 통합 시 한 번 검사한다. 마지막에 새 경계 사례를 다시 검토하고 README·소개·변경 기록을 갱신해 PR에 반영한다.

완료 근거: 실제 fixture 회귀, 설치 위치를 분리한 helper 실행, 최종 독립 검토, 현재 지문·CI. 인증된 설치 모델 행동이나 전후 토큰 비용은 측정하지 않았으면 미실행으로 기록한다.
