web의 동적 SQL 진단 8건과 미해소 관계는 결과에 그대로 남긴다. 미해소에는 정적 분석 대상 밖의 유틸리티·외부 타입 등이 포함된다. Mermaid 도메인은 Archify 배치 검증 통과로 집계하지 않았다. 두 소비 프로젝트의 소스는 수정하지 않았다.

## 검증 근거

- 최종 수정본의 아키텍처 관련 212개, 시각화 관련 135개 테스트 통과(총 347개).
- Codex 관련 215개 실행 중 WSL Bash 선택으로 실패한 모듈은 Git Bash를 우선하도록 환경을 지정하여 26개 전부 재실행 통과했다. 나머지 모듈은 최초 실행에서 통과했다.
- `sync-codex-resources.py --check`, `lint-consistency.sh` 통과. 이번 수정 파일의 `git diff --check`도 통과했다. 전체 검사에서는 보존한 사용자 변경 `decisions.md`의 기존 후행 공백 2곳이 검출되어 그대로 두었다.
- 실제 Chrome의 예제 7개 화면과 대형 프로젝트 4개 화면에서 JavaScript 예외·문서 가로 넘침 없음. 개요 검색 → 노드 위치/포커스, 빈 검색 결과, 다른 도메인 링크, 뒤로 이동 링크, 테마 저장/페이지 간 유지 확인. 대형 building 도메인은 118개 노드의 실제 Mermaid 렌더링을 확인했다.
- 동일 fixture·offline 조건 비교: 기존 1/12, 개선 반복 1은 11/12, 반복 2는 12/12. 실패 링크 잔존과 두 번째 API 경로 표시 누락을 평가 중 찾아 수정했다.
- 독립 검증에서 추가로 발견한 SQL 함수 내부 FROM, 다른 객체의 필드 호출, 마지막 소스 전체 삭제를 별도 회귀 테스트로 보완했다.
- 실제 프로젝트 확장 검사에서 인터페이스 throws 선언 오인, `IS [NOT] DISTINCT FROM` 오인, 하네스 worktree 복제본 중복 스캔을 추가로 수정하고 회귀 테스트를 통과했다.

평가는 에이전트가 스킬을 읽고 helper를 실행한 결과다. 오프라인 조건을 고정하기 위한 backend override를 사용했다. 모델 토큰·비용과 실제 설치 세션의 훅 동작은 측정하지 않았다. Archify 원래 도구 모음 일부는 영어를 유지하며 한국어 공통 탐색·범례·근거 목록을 덧붙였다. 자동 비교 점수는 전체 Java/SQL 의미 분석의 완전성을 뜻하지 않는다.

평가 뷰어·화면·로그는 이번 Codex 시각화 작업 폴더의 `gx-visualize-workspace/review.html`, `review-map/아키텍처-맵.html`, `final-*.png`, `*-final.log`에 보관한다.
