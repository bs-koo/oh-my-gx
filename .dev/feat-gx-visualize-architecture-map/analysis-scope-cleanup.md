# 분석 범위 안내 간소화

2026-10-16 사용자 피드백: 개요의 분석 범위 확인에서 같은 동적 SQL 설명과 Python dict 표현이 반복되어 프로젝트 구조 탐색을 방해했다.

`build_index.py`에서 진단을 유형별로 묶고 완전히 같은 항목을 제거한다. 기본 화면에는 분석 한계를 설명하는 한 문장과 닫힌 상태의 ‘세부 위치 보기’만 표시한다. 펼치면 유형별 설명을 한 번씩 표시하고 파일·행 링크를 제공한다. 읽기 실패, 문자열 형식의 예전 진단, 알 수 없는 유형도 유지하며 HTML 텍스트를 이스케이프하고 근거 링크를 프로젝트 안으로 제한한다. 스캔·IR·manifest의 원본 진단과 분석 결과는 바꾸지 않았다.

실제 web 프로젝트의 개요를 다시 생성했다. 원본 진단 95건은 표시상 61건·3유형으로 정리되며, 같은 배타 분기 설명은 1회 표시한다. 향후 맵 생성에도 같은 처리가 적용된다.

검증: index 테스트 15개 통과. Chrome의 데스크톱·모바일에서 기본 접힘, 열기·닫기, 근거 링크 61개, 내부 dict 표현 제거, 페이지 가로 넘침 없음과 브라우저 오류 없음을 확인했다. Codex 리소스 동기화 검사와 UI detector(`[]`)도 통과했다. 관련 로그와 화면은 이번 시각화 폴더의 `analysis-scope-*`, `scope-fixed-*`에 보관한다.
