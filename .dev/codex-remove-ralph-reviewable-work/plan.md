# 작업 범위

1. 첨부 글의 1차 출처와 연구 한계를 확인한다.
2. Ralph 스킬·외부 러너·전용 CI/검사를 제거하고 일반 TDD·커밋 보호를 유지한다. 과거 실행/잠금은 보존하고 실행 중단·명시 전환을 안내한다.
3. 기존 기록을 이용한 판단 이유·원문 출처·검증 범위 전달을 gx-work/context/TDD/verify에 짧게 연결한다. 강제 퀴즈·추가 승인·무조건 전체 로그·매번 별도 에이전트는 도입하지 않는다.
4. 관련 회귀, 통합 시 Codex 검사 1회, 생성물·hook·린트·PR CI를 확인한다. 완료 후 경계 검토를 별도 실행하고 필요한 수정만 재검사한다.
5. Git으로 공유한 `.dev`의 관련 결정·PRD·설계를 고정 revision에서 제한 조회하고, 후속 변경·현재 작업본·실제 응답자와 기록 기여자를 구분한다. 중요한 충돌은 기존 질문으로 확인하고 현재 결정에 출처와 변경 이유를 연결한다. 소비 프로젝트는 읽기 전용으로 살피며 실제 업무 기록은 공개 산출물에 복사하지 않는다.

이번 변경은 PR로 전달하며 머지·운영 배포를 자동 진행하지 않는다. 실제 설치/모델/사용자 이해도·비용 실측과 로컬 계약 검사를 구분한다.
